# 📢 Project Design Doc: "SCREAMER"
**Слоган:** *Социальная сеть, где размер имеет значение (размер громкости).*

***

## 1. Концепция и Функционал

Это новостная лента, управляемая **голосом**. Чем громче ты говоришь/кричишь, тем весомее твой контент и тем быстрее ты потребляешь информацию.

### MVP (Минимально жизнеспособный продукт — Цель на первые 4 часа)
1.  **Scream-to-Scroll:** Лента не скроллится пальцем/мышкой. Ты должен гудеть или кричать в микрофон. Громче звук -> быстрее скролл.
2.  **Volume-based Posting:** При создании поста ты зажимаешь кнопку "REC" и диктуешь (или орешь) текст.
    *   Шептал? Твой пост будет крошечным (8px), серым и незаметным.
    *   Орал? Твой пост будет гигантским (72px), красным и жирным.
3.  **Live Volume Meter:** Визуальный индикатор громкости (столбик или волна) на экране всегда.

### Phase 2 (Если успеваем — Цель на вторые 4 часа)
1.  **Destruction (Уничтожение):** У постов есть HP (здоровье). Если читатель орет, пока пост на экране — пост получает урон. Когда HP = 0, пост взрывается и удаляется.
2.  **WebSocket Sync:** Урон по постам синхронизируется между всеми пользователями в реальном времени.

## 2. Сущности и База Данных

*Для Бэкендера: Сразу создавай такие структуры (Go structs).*

### `User` (Упрощаем: без паролей, просто сессия)
*   `ID` (uint, PK)
*   `Username` (string) — генерируем рандомно, например "AngryBadger_42".

### `Post`
*   `ID` (uint, PK)
*   `Content` (string) — текст поста.
*   `InitialVolume` (int) — уровень громкости при создании (0-100). От этого зависит размер шрифта.
*   `CurrentHP` (int) — здоровье поста (по умолчанию 1000).
*   `IsDestroyed` (bool) — жив или мертв.

## 3. API Контракт (Contract)
*Чтобы Фронт и Бэк могли работать не ожидая друг друга.*

### REST API (HTTP)

1.  **`GET /api/posts`**
    *   **Response:** `[{ "id": 1, "content": "АААА!", "initial_volume": 90, "current_hp": 800 }, ...]`
    *   *Логика:* Отдавать только посты, где `is_destroyed = false`. Сортировка: новые сверху.

2.  **`POST /api/posts`**
    *   **Request:** `{ "content": "Всем привет", "initial_volume": 45 }`
    *   **Response:** `{ "id": 2, "status": "created" }`

3.  **`GET /api/health`**
    *   Проверка, что сервер жив.

### WebSocket (Realtime)
*Endpoint:* `ws://host/ws`

*   **Client -> Server (Атака):**
    ```json
    {
      "action": "scream_damage",
      "post_id": 12,
      "damage": 5  // вычисляется на фронте от громкости
    }
    ```
*   **Server -> Client (Обновление):**
    ```json
    {
      "event": "hp_update",
      "post_id": 12,
      "new_hp": 795
    }
    ```

## 4. Реализация и Задачи (Кто что делает)

### 3.1 Backend (Go + Gin + Gorm)
*Человек А: "Архитектор Хаоса"*

1.  **Setup:** `go mod init`, поставить Gin, GORM, WebSocket. Поднять Docker с Postgres.
2.  **Models:** Описать структуры `Post` и `User`. Сделать авто-миграцию.
3.  **CRUD:** Реализовать GET и POST для постов.
    *   *Совет:* Сделайте сидер (скрипт), который при старте заливает в базу 10 тестовых постов разной громкости, чтобы фронту было что отображать.
4.  **WebSocket Hub:** Написать простой хаб, который принимает сообщения и бродкастит (рассылает) их всем.

### 3.2 Frontend Logic (React + Hooks)
*Человек Б: "Повелитель Микрофона"*

1.  **`useAudioInput` Hook:** Самая важная часть.
    *   Запрашивает `navigator.mediaDevices.getUserMedia`.
    *   Создает `AudioContext` и `AnalyserNode`.
    *   Считает RMS (громкость) и нормализует её в число 0..100.
    *   Возвращает это число в компонент 60 раз в секунду.
2.  **Scroll Logic:**
    *   `useEffect` который смотрит на громкость.
    *   Если `vol > threshold` -> `window.scrollBy(0, vol * speed_coefficient)`.
3.  **API Client:** Написать функции `fetchPosts` и `createPost` (Axios или fetch).

### 3.3 Frontend Visual (React + Tailwind)
*Человек В: "Дизайнер Разрушения"*

1.  **Компонент `PostCard`:**
    *   Принимает проп `volume`.
    *   Вычисляет стиль: `style={{ fontSize: ${volume}px, fontWeight: volume > 80 ? 900 : 400 }}`.
    *   Если `volume > 90` — добавить CSS анимацию тряски.
2.  **Компонент `VolumeMeter`:**
    *   Столбик сбоку экрана, который прыгает вверх-вниз.
3.  **Главный экран:**
    *   Хедер с кнопкой "Создать пост" (открывает модалку).
    *   Список постов.
    *   *Важно:* Сделать заглушки данных, пока Бэк и Логик пишут код, чтобы верстать красоту сразу.
